# Currency Converter

A lightweight currency converter built with Node.js and browser-native HTML, CSS, and JavaScript. Exchange rates are fetched live from [ExchangeRate-API](https://www.exchangerate-api.com/) and cached by the server for five minutes.

## Requirements

- Node.js 18 or newer
- Internet access for live exchange rates

## Run

```sh
npm start
```

Then open [http://localhost:3000](http://localhost:3000). Set the `PORT` environment variable to use a different port.
